# Documentation (Tài Liệu Hệ Thống)

Tài liệu thiết kế kiến trúc, đặc tả API và hướng dẫn triển khai dự án.

## Cấu trúc:
- `architecture/`: Tài liệu kiến trúc Client - Server và N-Tier Architecture.
- `api/`: Đặc tả các endpoints RESTful API (Swagger / Postman).
- `database/`: Từ điển dữ liệu và sơ đồ quan hệ các bảng.
